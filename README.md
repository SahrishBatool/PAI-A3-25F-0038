
# Programming for AI - Assignment 3

## Overview
This repository contains the complete submission for Assignment 3 of the Programming for AI course. The project involves NumPy data manipulation, array broadcasting, memory view analysis, multidimensional array operations, and dynamic data visualization using Matplotlib.

## Repository Structure
```text
.
├── Assignment3_Programming_for_AI.ipynb  # Main Jupyter Notebook
├── README.md                              # Project documentation
├── data/                                  # Input datasets
│   ├── sensor_cube.npy
│   ├── sensor_meta.npz
│   ├── student_performance.csv
│   └── weather_stations.csv
└── outputs/                               # Generated visual deliverables
    ├── dashboard.pdf
    ├── dashboard.png
    └── wave.gif
Key Deliverables Included
    dashboard.png: High-resolution multi-panel data visualization dashboard.
    dashboard.pdf: Exported PDF format of the summary visualization dashboard.
    wave.gif: Animated wave plot generated via Matplotlib showing frame-by-frame NumPy calculations.

Dependencies & Requirements
The code requires Python 3.x and the following standard scientific libraries:

    numpy
    matplotlib
    jupyter

Instructions to Run
    Extract or clone the repository maintaining the folder structure.
    Open your terminal or Jupyter environment in the root directory.
    Launch the notebook:
          jupyter notebook Assignment3_Programming_for_AI.ipynb
    Execute all notebook cells sequentially.
